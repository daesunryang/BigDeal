# 집중냥 개발 인계 문서 (프로토타입 v2)

원본: `집중냥 App.dc.html` · 변경 이력과 피드백: `집중냥 업데이트 내역.dc.html` · 디자인 토큰: `집중냥 디자인 시스템.dc.html`
플랫폼: Android 우선, iOS 확장 · 화면 360×760 기준

## 1. 핵심 루프
시계 탭 → 집중 설정 창(종료 시각 12시간 AM/PM + 휴식 주기 n분마다 x분, 프리셋 25·5/50·10/90·15/없음 또는 ± 직접 조절) → 차단 제외 앱 선택 → 집중 시작 → 카운트다운 → 완료/포기
- 홈: 스크롤 없는 한 화면. 츄르 잔액은 홈에 표시하지 않고 사용처(방 꾸미기·상점)에서만 보임. 우측 상단 오늘 목표 달성률(탭 → 집중 기록). 오늘 집중 상세는 메뉴 › 집중 기록.
- 집중 설정 창이 열리면 바깥은 비네팅으로 어두워지고 홈 애니메이션·행동 주기가 멈춤(`wheel`). 집중 중 휴식 주기가 되면 타이머가 멈추고 휴식 화면으로 자동 전환, 휴식이 끝나면(또는 "바로 집중 이어가기") 남은 집중으로 복귀(`restOn`, `restEvery`, `restLen`, `midRest`). 완료 후 휴식은 `restLen`분.
- 홈에서 고양이 직접 탭 = 노래. 기본 5곡 + 품종별 전용 1곡(8곡) 중 지금 고양이가 부를 수 있는 곡에서 랜덤, 같은 곡 연속 없음(`SONGS`, `singUntil`). 처음 들은 곡은 도감 › 노래에 수집(`seenSongs`), 다시 듣기 가능.
- 노래 수집 보상: 기본 5곡 완성 츄르 20, 전용 8곡 완성 츄르 50(각 1회, `songBonus`). 배지 "노래 수집" 3·5·9·13곡. 방 배경 탭 = 우리 집 평면도.
- 완료: 츄르 = 분×0.4(반올림), 친밀도 = max(3, 분/2.5). 파트너가 사료 100g 기부. 하루 목표 달성 시 배너. 연속 집중 일수 갱신.
- 포기: 보상 없음, 친밀도 -3(엄격 모드 -6), 고양이 시무룩이 다음 성공까지 유지.
- 친밀도 20마다 하트 1개(표정 6단계). 40/80에서 성장 단계(아기→어린→어른, 크기 .74/.88/1).
- 집중 중: 타이머 화면 아래 우리 집 미니맵에서 고양이가 방을 옮겨 다니고(6초 주기), 방을 옮기면 안내가 뜸. "고양이 부르기"는 거실로 이동(30초 고정).

- 도감: 아직 열지 않은 고양이는 Plus 포함 이름 ???.

## 3. 우리 집(평면도) 규칙
- 방 7개: 거실(기본), 낮잠방(기본 해금), 놀이방 60·간식 주방 80·마당 120 츄르로 해금, 다락방·서재는 "집 넓히기 200 츄르"로 한꺼번에 열림.
- 방 한 번 탭 = 선택(설명 표시), 두 번 탭(450ms) = 고양이 이동 후 1초 뒤 팝업 닫힘. 이동 후 60초 동안 고정, 이후 행동으로 이동: 낮잠→낮잠방, 두리번→마당, 콩콩→놀이방, 간식→주방, 시무룩→낮잠방. 해금 전이면 거실.
- 방마다 벽지·바닥·가구·위치를 따로 저장(`rstore`). 옷은 고양이 소유라 모든 방에서 공통. 방 이름 변경 가능(최대 10자).
- 방 전용 가구 14종(`SPECIAL`), 공용 가구·소품·간식·시즌 한정(한정: 마녀 모자·호박 쿠션·낙엽 러그·유령 가랜드).
- 보류: 미니어처 성(집이 더 커졌을 때 성 규모 전체 보기). 평면도 구조를 확장하는 방향.

## 5. 규칙
- 엄격 모드: 포기 버튼 숨김, 긴급 종료 3초 길게(친밀도 -6), 안내 최소화. 시스템 뒤로가기도 집중 중에는 막힘.
- 전화·알람: 타이머 일시정지, 벌점 없음. 세션 복구: 3분 안 복귀 시 이어하기.
- 광고 보상: 하루 3회, 5초 시청, 츄르 +5. 간식: 참치 10(+3), 북어 6(+2), 우유 8(+2).
- 결제 후원: 약관 3개 필수 동의, 전달 전 7일 이내 환불 요청 가능, 츄르 후원은 환불 불가.
- 다크 모드: 전용 팔레트(CSS 변수). 메뉴에서 시스템/라이트/다크 선택. 방·고양이 그림은 색 유지.
- 큰 글씨: 화면 약 10% 확대. 색약 대응: ♥/♡·켜짐/꺼짐 글자 병기.
- 언어: 한국어 기본, English/日本語는 주요 화면 문구만 번역(나머지는 한국어). 실제 앱은 문자열 리소스로 이전.
- 뒤로가기: 팝업 → 시트 → 하위 화면 → 탭 → 홈 → "한 번 더 누르면 종료".

## 6. 효과음·햅틱
시작/완료/포기/츄르/구매/고양이 탭(노래 5곡) — 프로토타입은 WebAudio 합성. 실제 앱은 음원으로 교체. iOS 햅틱은 Taptic Engine 매핑.

## 7. 이미지 슬롯(교체 필요)
`image-slot` 칸: 상점 아이템 6, 보호소 카드 2, 보호소 전경 2, 보호소 동물 4, 소식 피드 4, 우편 사진, 파트너 로고. 고양이 행동별 전용 그림은 없음(같은 그림 + 이펙트).

## 8. 미정·교체 필요
