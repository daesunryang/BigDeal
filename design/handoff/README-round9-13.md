# Handoff: 집중냥 — 홈 정리 · 집중 설정 · 노래 도감 · 휴식 자동 전환 (라운드 9–13)

## Overview
기존 집중냥 구현(Claude Code 쪽 아티팩트)에 이번 디자인 라운드 9–13 변경을 반영하기 위한 패키지입니다. 앱 전체 명세는 `개발 인계 문서.md`, 이번에 바뀐 부분은 아래 "변경 사항"이 기준입니다. **이미 구현된 화면은 건드리지 말고, 아래 항목만 바꾸세요.**

## About the Design Files
이 폴더의 HTML은 **디자인 레퍼런스(프로토타입)** 입니다. 그대로 배포하는 코드가 아니며, 기존 코드베이스의 프레임워크·패턴으로 동일한 화면과 동작을 다시 구현하는 것이 목표입니다.
- `집중냥 프로토타입 (공유본).html` — 단일 파일, 오프라인으로 바로 열림(가장 쉬운 확인용)
- `집중냥 App.dc.html` — 원본 소스(템플릿 + 로직 클래스). 같은 폴더의 `support.js`, `assets/`가 필요

## Fidelity
**High-fidelity.** 색·타이포·간격·문구가 확정값입니다. 화면 기준 360×760(안드로이드 우선).

## 변경 사항

### 1. 홈 — 스크롤 없는 한 화면 (라운드 9, 13)
- 홈 컨테이너: `flex:1; min-height:0; overflow:hidden; display:flex; flex-direction:column; justify-content:space-between; gap:12px; padding:6px 18px 18px`. **스크롤 없음**(스크롤은 메뉴 탭 등에서만).
- 위→아래 순서: ① 헤더(40px) ② 방 그림(고양이) ③ 시계 묶음 ④ 집중 시작 버튼.
- **삭제**: 헤더의 츄르 잔액 칩, 고양이 이름·성장 단계·표정·하트 줄, "얼마나 집중할까요?" 제목, 24/12시간 토글, 목적 태그 칩, "집중 시간 n분" 문구, 오늘 집중 카드(→ 메뉴 › 집중 기록으로 이동), 시작 버튼의 "보상 n 츄르" 문구.
- **재화 노출 규칙**: 츄르 잔액은 사용처(방 꾸미기, 상점 등)에서만 보임. 홈에는 표시하지 않음.
- 헤더: 좌 "집중냥"(Jua 24px). 우 **오늘 목표 칩** — 높이 30, radius 15, border 1.5px `--line`, 배경 `--bg`; "오늘 목표"(12px `--sub`) + "nn%"(Jua 14px) + 28×4 막대(트랙 `--line`, 채움 `#E59A4C`). 탭 → 집중 기록.
- 시계 묶음(세로 gap 10):
  - 카드: padding 12, radius 20, 배경 `--card`. 안에 시계 버튼(전체 폭, padding 14px 0, radius 22).
  - 시계 표시 = **집중 종료 시각, 12시간 AM/PM 전용**. "오후"/"오전"(Jua 22px `#E59A4C`) · 시(Jua 54px, tabular-nums) · ":"(Jua 48px) · 분(Jua 54px). 박스 안에는 시계만.
  - 아래 버튼 2개(flex 1:1, gap 8, 높이 42, radius 21, Jua 14px, nowrap):
    - "휴식 · {n}분마다 {x}분" (휴식 없음이면 "휴식 · 휴식 없음") — border 1.5px `--ink`, 배경 `--mint`. 탭 → 집중 설정 창.
    - "{n}개앱 차단 제외 ›" — border 1.5px dashed `--sub`, 투명. n = 차단 대상에서 **제외된** 앱 수. 탭 → 앱 선택 시트.
- 시작 버튼: 높이 56, radius 28, 배경 `--ink`, 글자 `--bg`, Jua 20px, "집중 시작".

### 2. 집중 설정 창 (시계 탭) (라운드 9)
- 종료 시각과 휴식 주기를 **한 창에서** 설정.
- 오버레이(상태바 아래 전체): `radial-gradient(ellipse 70% 58% at 50% 50%, rgba(24,16,11,.2), rgba(24,16,11,.86))` + `backdrop-filter: grayscale(.7) blur(2px)` → **비네팅**. 바깥 탭 = 닫기.
- 창이 열린 동안 홈의 모든 애니메이션 일시정지, 고양이 행동 주기(6초)도 정지.
- 창: 배경 `--bg`, border 2px `--ink`, radius 26, padding 18, 세로 gap 14.
  - 제목 "집중 설정"(Jua 20) + 요약 "지금부터 {h}시간 {m}분 집중해요"(12px `--sub`)
  - "집중 종료 시각" — 휠 3열(오전/오후 · 시 1–12 · 분), 높이 160, 항목 40px, scroll-snap, 중앙 하이라이트 `--card`, 위아래 페이드.
  - "휴식 주기" — 프리셋 4개 그리드(25분·5분 / 50분·10분 / 90분·15분 / 휴식 없음), 높이 44, radius 14; 선택 시 배경 `--ink`·글자 `--bg`.
  - 직접 조절(카드 `--card`, radius 16): 2줄 그리드 `32px 34px 32px auto`
    - [−] {n} [+] 분마다 — 5분 단위, 5–180
    - [−] {x} [+] 분 휴식 — 1분 단위, 1–30
    - ± 조작 시 자동으로 휴식 켜짐. 휴식 없음이면 이 영역 opacity .45.
  - "확인" 버튼: 높이 50, radius 25, `--ink`.
- 기본값: 휴식 켜짐, 25분마다 5분.

### 3. 휴식 자동 전환 (라운드 13)
- 집중 중 경과 시간이 `restEvery`분의 배수에 닿으면: 효과음 + 토스트 "{n}분 집중했어요 · {x}분 쉬어 가요" → **타이머 정지, 휴식 화면으로 전환**(휴식 `restLen`분).
- 휴식 화면 문구: 도중 휴식이면 "휴식이 끝나면 남은 집중을 이어서 해요." / 버튼 "바로 집중 이어가기". 완료 후 휴식이면 기존대로 "시간이 끝나면 홈으로 돌아가요." / "휴식 끝내고 홈으로".
- 휴식 종료 시: 도중 휴식 → 토스트 "다시 집중해요" + 남은 시간으로 집중 재개. 완료 후 휴식 → 홈.
- 같은 주기에서 중복 발동 금지(마지막 발동 회차 기억).

### 4. 고양이 탭 = 노래 (라운드 9, 10, 12)
- 홈에서 **고양이를 직접 탭** → 노래. **방 배경 탭**은 기존대로 우리 집 평면도.
- 노래 중: 말풍선(가사) + 음표 4개(♪♫♪♬)가 위로 떠오름(1.6s 반복, 0/.5/1/1.4s 지연), 몸은 meow 애니메이션. 지속 = 곡 길이 + 0.9s(최소 2.6s).
- 곡 풀 = 기본 5곡 + **지금 고양이의 전용 곡 1곡**. 무작위, 같은 곡 연속 금지.
- 곡 목록(이름 · 가사):
  - 기본: 냐옹냐옹 왈츠 · "야옹야옹~ 냐옹냐옹♪" / 츄르 송 · "냥냥냥~ 츄르 송♫" / 낮잠 자장가 · "골골~ 자장자장 야옹♪" / 신나는 냥 · "미야우! 신나는 냥♬" / 아침 인사 · "야~옹 야~옹 아침 냥♪"
  - 전용: 치즈태비 햇살 항아리 · 흰색 조용한 밤 · 삼색 수다 폭발 · 검은색 턱시도 행진 · 랙돌 포근한 안기 · 샴 수다쟁이 아리아 · 페르시안 느긋한 오후 · 터키시 앙고라 두 빛깔 왕국
  - 음 높이·길이 데이터는 원본 `SONGS` 상수 참고(프로토타입은 WebAudio 삼각파 합성 → 실제 앱은 음원으로 교체).
- 효과음 꺼짐이면 소리 없이 애니메이션만.

### 5. 도감 (라운드 9, 11, 12)
- **열지 않은 고양이 이름은 Plus 고양이 포함 전부 "???"**.
- 탭 4개: 고양이 / 행동 / **노래** / 아이템. 노래 탭 카운트 "{n}/13 수집".
- 노래 카드: 40px 아이콘(수집: 기본 ♪ `--mint`, 전용 ♬ `--chip1` / 미수집: ? `--card2`), 제목 "{곡명} · 기본" 또는 "{곡명} · {고양이} 전용"(못 만난 고양이면 "??? 전용"), 가사. 미수집은 곡명 ???.
- 수집된 곡만 "▶ 듣기" 버튼(소리만 재생, 수집 상태 변화 없음).
- 처음 듣는 곡 → 토스트 "새 노래 · {곡명} 수집!". 첫 곡(냐옹냐옹 왈츠)은 기본 수집.
- 보상(각 1회): 기본 5곡 완성 → 츄르 20, 전용 8곡 완성 → 츄르 50. 츄르 내역에 기록.
- 배지 추가: "노래 수집" 3·5·9·13곡.
