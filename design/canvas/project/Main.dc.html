냥집중

방해 앱을 막고 집중하면 고양이가 자라고, 모은 츄르는 실제 보호소 고양이의 사료가 됩니다.

핵심 루프
0. 스플래시 → 로그인(Google/이메일) → 권한 허용
1. 시간·차단 앱 선택 → 집중 시작
2. 차단 앱 실행 시 오버레이로 막음
3. 완료 → 츄르 + 친밀도 하트 → 표정 변화
4. 목표 달성마다 파트너가 보호소에 사료 대신 기부
5. 츄르로 새 고양이·방 꾸미기
Android 우선 · iOS 확장
Android: UsageStats + 다른 앱 위에 표시(오버레이)로 차단. Material 3 하단 내비, 시스템 뒤로가기 대응.
iOS: Screen Time(FamilyControls) 권한, 차단 화면은 Shield 확장으로 대체. 레이아웃은 동일, 상태바·홈 인디케이터만 교체.
실제 앱 v1.3.0 반영
뒤로가기는 바로 전 화면으로 (탭·메뉴 하위 화면·방 꾸미기 기록). 앱 정보의 업데이트 확인, 새 버전 안내 배너, 화면 오류 복구 화면. 메뉴 → 데모 상황에서 확인해요.
Tweaks: 플랫폼 전환, 홈 레이아웃 3종(방 카드 / 풀블리드 / 원형), 타이머 레이아웃 3종(링 / 방 / 나이트), 빠른 타이머.
