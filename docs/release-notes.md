방해 앱을 막고 집중하면 고양이가 자라고, 모은 츄르로 보호소 고양이를 후원해요.

## v1.2.1에서 달라진 점
- 앱을 열 때 새 버전이 있으면 바로 업데이트할지 물어봐요
- 도감에서 못 만난 고양이도 실루엣이 보여요

## v1.2.0에서 달라진 점
- **iOS 버전이 생겼어요** (아래 "iOS 파일" 참고)
- 홈의 휴식 버튼을 "25분마다 / 5분 휴식" 두 줄로 정리, 뒤로가기로 돌아오면 이전 스크롤 위치를 기억
- 앱 이름 '냥집중'에 맞춰 앱 ID를 새로 바꿨어요 (`com.nyangjibjung.app` / `com.nyangjibjung.demo`)
- **이전 앱(집중냥)과는 다른 앱으로 설치돼요.** 새 앱을 설치한 뒤 이전 앱은 지워 주세요. 이전 앱의 기록은 옮겨지지 않아요.

## v1.1.1에서 달라진 점
- 앱 이름이 '냥집중'으로 바뀌었어요 (기존 앱 위에 그대로 설치하면 기록이 이어져요)
- 홈을 스크롤 없는 한 화면으로 정리 (오늘 목표 칩, 오전/오후 시계, 휴식 · 차단 제외 버튼)
- 시계를 누르면 집중 설정 창: 종료 시각 + 휴식 주기 (25·5 / 50·10 / 90·15 / 없음, 직접 조절)
- 집중 중 휴식 주기가 되면 휴식 화면으로 자동 전환, 끝나면 남은 집중을 이어서
- 고양이를 누르면 노래 (기본 5곡 + 고양이별 전용 곡), 도감 › 노래 탭에서 수집 · 다시 듣기 · 수집 보상
- 뒤로가기가 항상 바로 전 화면으로 돌아가요 (예: 도감 → Plus 페이지 → 뒤로 = 도감)

## v1.1.0에서 달라진 점
- 실제 알림(정식): 요일·시간 집중 리마인더, 목표 달성 알림
- 업데이트 확인: 새 버전이 나오면 메뉴 맨 위에 안내, 눌러서 바로 APK 받기
- 영수증·누적 증명서를 실제 PDF로 공유
- 매일 출석 보상 우편(정식), 오류가 나도 앱이 꺼지지 않는 복구 화면, 접근성 개선
- 이전 버전 위에 그대로 설치하면 기록이 이어져요. 자세한 내용은 CHANGELOG.md

## 두 가지 APK

| 파일 | 내용 |
|---|---|
| `nyangjibjung-v….apk` · **정식** (`com.nyangjibjung.app`) | 실제 앱 차단(Android), 설치된 앱 목록, Google·이메일 로그인과 자동 동기화(Firebase 설정 시) |
| `nyangjibjung-demo-v….apk` · **데모** (`com.nyangjibjung.demo`) | 프로토타입과 같은 UI 데모. 차단·로그인은 흉내만 내고 타이머는 30배속 |

패키지 이름이 달라서 두 앱을 한 휴대폰에 같이 설치할 수 있어요.

## iOS 파일

| 파일 | 내용 |
|---|---|
| `nyangjibjung-ios-v….ipa` · 정식 / `nyangjibjung-ios-demo-v….ipa` · 데모 | 아이폰용. **아직 Apple 서명이 없어요.** AltStore나 Sideloadly 같은 도구에서 내 Apple ID로 서명해 설치해요 (무료 Apple ID는 7일마다 다시 서명해야 해요) |
| `nyangjibjung-ios[-demo]-simulator-v….zip` | Mac의 Xcode iOS 시뮬레이터용. 압축을 풀어 시뮬레이터 창에 끌어다 놓으면 실행돼요 |

- iOS에서는 다른 앱 차단이 아직 동작하지 않아요 (Apple의 스크린 타임 권한 승인이 필요해요). 타이머·고양이·도감·후원 화면은 Android와 같아요.
- 앱스토어·TestFlight로 배포하려면 Apple Developer 계정(연 $99)과 서명 인증서가 필요해요. 준비되면 워크플로에 서명을 붙일 수 있어요.

## 설치
1. 휴대폰에서 APK를 내려받아 엽니다. "출처를 알 수 없는 앱 설치"를 허용해야 할 수 있어요.
2. 정식 앱은 처음 실행 때 **사용 정보 접근**과 **다른 앱 위에 표시**를 허용해야 앱 차단이 동작해요.

## 알아 둘 것

- 정식 앱의 Google 로그인과 동기화는 저장소에 Firebase 비밀값을 넣은 뒤 빌드해야 동작해요. 없으면 이 기기에만 저장돼요.
